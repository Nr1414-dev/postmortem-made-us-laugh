`main.py` writes one short two-sentence postmortem (under 400 characters) to `/output/entry.txt`:

> I asked the agent to merge the duplicate accounts. It merged every user named John into one account — John now has 4,000 orders, 12 addresses, and a restraining order against himself.

The line was picked from 10 candidates scored against the judge's brief, then checked 1v1 against the field: "John" / "merge" / "restraining order" score 0 hits across all 512 field titles, while the usual postmortem angles (rename one variable, cleanup dead code, delete the test suite, drop the users table) are saturated.
